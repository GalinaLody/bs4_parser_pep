# Описание проекта
bs4_parser_pep - это парсер документации Python и PEP. Парсер может в отношении документации Python:
- собирать ссылки на статьи о нововведениях в Python, переходить по ним и забирать информацию об авторах и редакторах статей;
- собирать информацию о статусах версий Python;
- скачивать архив с актуальной документацией;
Парсер может в отношении документации PEP:
- сравнить статус на странице PEP со статусом в общем списке;
- собрать информацию о количестве PEP в каждом статусе и общее количество PEP.

## Технологический стек проекта.
- Python 3.9

### Как запустить проект Yacut:

Клонировать репозиторий и перейти в него в командной строке:

```
git clone git@github.com:GalinaLody/bs4_parser_pep.git
```

```
cd bs4_parser_pep
```

Cоздать и активировать виртуальное окружение:

```
python3 -m venv venv
```

* Если у вас Linux/macOS

    ```
    source venv/bin/activate
    ```

* Если у вас windows

    ```
    source venv/scripts/activate
    ```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```
## Примеры запуска парсера
Для запуска парсера перейдие в директорию src:

```
cd src
```

Режимы работы парсера:
- whats-new - собрать ссылки на статьи о нововведениях в Python, переходить по ним и забирать информацию об авторах и редакторах статей;
- latest-versions - собрать информацию о статусах версий Python;
- download - скачать архив с актуальной документацией Python
- pep - собрать информацию о количестве PEP в каждом статусе и общее количество PEP.

Пример команды:
```
python main.py pep
```
Способы вывода данных:
- pretty - вывод данных в формате таблицы в терминал;
- file - сохранение данных в файле в формате csv.

Пример команды:
```
python main.py pep --output file
```
Более подробная информация об имеющихся командах:
```
python main.py -h
```
